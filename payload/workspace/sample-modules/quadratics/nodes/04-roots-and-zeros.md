## What this node is

A **root** (or **zero**) of a quadratic is an `x` value where `y = 0` — geometrically, where the parabola crosses the x-axis. A quadratic has 0, 1, or 2 real roots.

## Fluency exercises

1. Find the roots by factoring: `x² - 5x + 6 = 0`
2. Find the roots: `x² - 9 = 0`
3. Find the roots: `2x² + 7x + 3 = 0`
4. From `y = (x - 4)(x + 1)`, state the roots immediately.

## Schema-building exercises

1. **Zero product property.** Why does `(x - 2)(x - 3) = 0` imply `x = 2` or `x = 3`? Why doesn't this work for, say, `(x - 2)(x - 3) = 6`?
2. **How many roots?** Sketch parabolas with 0, 1, and 2 real roots. What condition on the graph determines which case? (Sets up the discriminant at `07`.)
3. **From roots, reconstruct the quadratic.** Given roots at `x = -1` and `x = 4`, write three different quadratics with those roots. What's the same across them? What's different?
