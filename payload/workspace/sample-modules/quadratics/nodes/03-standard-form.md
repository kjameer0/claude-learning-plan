## What this node is

`y = ax² + bx + c`, where `a ≠ 0`. The default written form of a quadratic. Not the most informative form — it makes the y-intercept obvious (`c`) but hides the vertex.

## Sources
- Algebra 1 textbook section on quadratic functions
- Desmos: graph `y = ax² + bx + c` and slide `a`, `b`, `c` to feel what each controls

## Fluency exercises

1. Identify `a`, `b`, `c` in: `y = 3x² - 4x + 2`, `y = -x² + 5`, `y = x² + x`
2. Evaluate `y` at `x = 0, 1, 2` for `y = 2x² - 3x + 1`
3. From `y = (x - 2)(x + 5)`, write in standard form

## Schema-building exercises

1. **What does each coefficient control?** Using Desmos, vary `a`, `b`, `c` one at a time. Describe in words what each does to the graph. Why does `a` control "width" and orientation? Why does `c` set the y-intercept?
2. **Why is `a ≠ 0` required?** What happens to the graph if `a = 0`? What kind of function is it then?
3. **From two roots, build standard form.** If a quadratic has roots at `x = 2` and `x = -5`, write it in standard form. Now: how many quadratics have those roots? (Answer: infinitely many — what's the family?)

## Metacog checks
- **Explanation**: Why is `c` the y-intercept? (Substitute `x = 0`.)
- **Transfer**: Given a parabola sketched on paper with visible roots and y-intercept, write its equation.
- **Connection**: How does standard form relate to factored form (`02`) and vertex form (`05`)? What does each reveal that the others hide?
