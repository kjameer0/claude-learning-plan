# 01 — Expanding (FOIL)

## Prereqs
- Distributive property
- Combining like terms

## Enables
- `03 standard-form` (recognizing standard form as the expanded product)
- `02 factoring` (reversible understanding)

## Sources
- Khan Academy: "Multiplying binomials"
- Any Algebra 1 textbook chapter on polynomial multiplication

## Fluency exercises (the floor)
Goal: do these without conscious effort. Aim for 10 in a row, clean.

1. `(x + 3)(x + 5)`
2. `(x - 4)(x + 2)`
3. `(2x + 1)(x - 3)`
4. `(x - 7)(x - 1)`
5. `(3x + 2)(2x - 5)`

## Schema-building exercises (the flight)

1. **Why does FOIL work?** Explain it using only the distributive property — no mnemonic. (FOIL is `a(c+d) + b(c+d)` expanded twice.)
2. **Generalize.** What is `(a + b)(c + d + e)`? Predict the number of terms before expanding. Now `(a + b + c)(d + e + f)`?
3. **Inverse intuition.** Given `x² + 7x + 12`, what two binomials would expand to this? (Sets up factoring.)

## Metacog checks
- **Explanation**: Can you derive FOIL from distribution on the spot, without the acronym?
- **Transfer**: Can you expand `(x + 2)³` by applying FOIL twice?
- **Connection**: How does this relate to `02 factoring` and to the distributive property itself?
